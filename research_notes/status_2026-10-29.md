## What we learned today

- Nsight (2.1M jittered): DRAM <1 %, L2 hit 99 %. Lean: 16-thread blocks (48 KB scratch
  limit), occupancy 7.8 %, 5.4 active of 32 lanes. Warp: 130 regs, occupancy 16.7 %,
  15.6 active lanes, issue 42 %. The rebuild is divergence-bound, not memory-bound.
- No gain: Morton cell order (±1 %), coarser cell lists (up to 2x slower), fast-math,
  40-slot lean double (worse on uniform). Small gain: register cap 5 blocks/SM (+4 %, kept).
- Uniform random cells test 45 candidates for 17.7 cuts (jittered 24 for 16.4): this,
  not scheduling, is most of the 2x gap.
- CPU replay (`shell_voronoi_check N <layout> cullstats`): per-octant radii would reject
  9 % / 28 % / 38 % of tests (jittered / uniform / clustered); 26 directions no better;
  only ~1/3 of vertices can be cut by a given candidate on irregular input.
- Octant culling in the warp kernel (per candidate, and per cell-list cell) cut tests as
  predicted but made it slower (jittered 18.2 -> 15.0, uniform 9.8 -> 7.9): a non-cutting
  test is already cheap there (2 vertices per lane + vote), and keeping octant radii costs
  atomics per cut. Reverted. Adding octant culling of whole cell-list cells (job 31655411,
  gpu1) gave jittered 14.5, uniform 7.8, clustered 0.99 (+8 % over 0.92): only clustered
  gains. Might still pay in a thread-per-cell kernel where a test loops over all vertices.
- Clustered input is the worst case: 169 tests, 37 cuts per cell, 16-20x slower than
  jittered. One cell-list size cannot fit clusters and voids -> multi-level cell list.
- Correctness: warp-double on uniform random leaves some face pairs inconsistent
  (faces=2*owned:NO, tolerance); exact tet repair handles it, clipping alone is not watertight.
- sc@1e-6 lattice: flip repair's local rebuild fails often (unrepaired 742-2339 per step);
  shells@1e-9 run timed out. Open.
- Literature (reports/Warp divergence in irregular GPU kernels.md): none of persistent
  threads, tail deferral, sub-warp teams, stage splitting, cost sorting, branch-free code has
  published 2x evidence for clipping; per-cut stage splitting would be slower.
